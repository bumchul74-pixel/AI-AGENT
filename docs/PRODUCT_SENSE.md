# 제품 원칙

조직의 표준 Java 패턴을 빠르게 적용해야 하는 개발자와 리뷰어가 주요 사용자다.

## 핵심 가치

- 표준 코드와 문서를 다시 찾는 시간을 줄인다.
- 생성 코드의 근거를 확인할 수 있게 한다.
- 반복 가능한 Java 계층과 test 생성을 지원한다.
- Provider나 검색 인프라 변경이 사용자 workflow를 깨뜨리지 않게 한다.

## 우선순위

1. 근거 정확성과 추적 가능성
2. 생성 코드의 컴파일·테스트 가능성
3. 비밀정보와 업로드 데이터의 안전
4. 장애 시 명확한 오류와 복구 가능성
5. 응답 속도와 편의성

검색 결과가 불충분할 때 그 사실을 알리는 것이 근거 없는 코드를 빠르게 생성하는 것보다 중요하다.
