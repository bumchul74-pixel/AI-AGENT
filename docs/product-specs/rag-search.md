# RAG 검색 결과 탐색

## 목표

개발자는 프로젝트별 RAG 검색 결과를 목록에서 선택하고, 검색 근거가 된 원문 chunk 안에서 검색어가 등장한 위치를 빠르게 확인할 수 있어야 한다.

## 사용자 흐름

1. 사용자는 프로젝트, 검색어, 조회 건수를 입력해 RAG 검색을 실행한다.
2. 화면은 검색 결과를 좌측 목록에 표시하고 첫 결과를 기본 선택한다.
3. 사용자가 목록 항목을 선택하면 우측에 해당 원문 chunk와 줄 번호를 표시한다.
4. 실행한 검색어와 일치하는 모든 줄은 강조하고, 정확히 일치한 문자열은 더 강하게 강조한다.
5. 여러 검색어는 공백으로 구분하며 따옴표로 감싼 문자열은 하나의 구문으로 취급한다.
6. 사용자는 일치 건수와 현재 위치를 확인하고 이전·다음 버튼으로 일치 항목을 순환 탐색할 수 있다.

## 검색어 강조 규칙

- 검색은 대소문자를 구분하지 않는다.
- 검색어는 정규식이 아닌 일반 문자열로 취급한다.
- 결과 선택 또는 검색 실행 시 첫 일치 항목으로 자동 이동한다.
- 일치 항목이 없으면 원문을 그대로 표시하고 탐색 버튼을 비활성화한다.
- 원문은 React 텍스트 노드로 렌더링하며 HTML로 해석하지 않는다.

## 상태와 실패 처리

- 빈 검색어, API 오류는 전역 Toast 정책을 따른다.
- 검색 결과가 없으면 목록의 빈 상태를 표시한다.
- 원문을 선택하지 않은 상태에서는 상세 안내를 표시한다.
