# 연계 시스템 상태 모니터링

## 결과

운영자는 AI-AGENT와 연계 시스템의 최근 점검 결과를 운영 관리에서 확인하고, 대시보드에서 전체 상태를 빠르게 파악할 수 있다.

## 요구사항

1. Backend, PostgreSQL, Python RAG, AI-MCP, EasyOCR MCP, Neo4j, 선택된 LLM Provider 상태를 표시한다.
2. 상태는 `UP`, `DEGRADED`, `DOWN`, `UNKNOWN`으로 구분한다.
3. 시스템별 중요도, 점검 유형, 응답 시간, 최근 점검 시각과 안전한 상태 메시지를 표시한다.
4. 기본 조회는 캐시된 최근 결과만 반환한다.
5. 사용자가 `지금 점검`을 실행한 경우에만 요청 흐름에서 즉시 전체 점검한다.
6. background 점검은 설정된 주기로 snapshot을 갱신한다.
7. 핵심 의존성이 DOWN이면 전체 DOWN, 선택 의존성이 DOWN이면 전체 DEGRADED로 집계한다.
8. LLM은 상태 화면에서 실제 생성 요청을 보내지 않고 설정 상태만 확인한다.
9. 대시보드는 전체 상태, 정상 시스템 수, 최근 점검 시각을 표시하고 상세 화면으로 이동할 수 있다.
10. 상태 조회 실패는 전역 Toast로 표시하며 동일 오류를 인라인으로 중복 노출하지 않는다.

## 실패 조건

timeout, 연결 거부, 잘못된 endpoint, probe 예외는 해당 시스템의 DOWN 또는 UNKNOWN 상태로 변환한다. credential, stack trace, 전체 외부 응답 본문은 사용자에게 반환하지 않는다.
